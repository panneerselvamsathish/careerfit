careerfit — architecture and flow

A fixed sequential pipeline (prompt chaining), not hub-and-spoke: no coordinator model, no subagents, no Task tool, no tool use. The only orchestrator is plain Python (the composition roots).

A --deep run, step by step

At most four model requests per run: two prompts, each with one possible retry. None if nothing needs judging.

sequenceDiagram
  participant CLI as cli.py (code)
  participant AN as analyze/ (rules)
  participant J as judge/
  participant C as cache.py
  participant M as Claude

  CLI->>AN: build_facts(resume, JD, ontology, at)
  AN-->>CLI: facts with statuses, levels, cited lines
  CLI->>J: judge_facts(facts)
  alt some skills UNRESOLVABLE
    J->>C: skill_match prompt with JSON schema
    C->>M: only on a cache miss
    M-->>J: verdicts
    J->>J: validate in code (quote on one line, 3+ words, JD line listed)
    opt problems found
      J->>M: one retry with the problems appended
    end
  end
  alt some skills GAP
    J->>M: learning_path prompt (same validation, one retry)
  end
  J->>J: compute_fit_score() is arithmetic, no LLM
  J-->>CLI: judged facts + JudgeRun (model, prompts, dismissed, failures)
  CLI->>CLI: render report, write files
